## Minimum submission packet

Use the product's verified name, short tagline, 100-character registry description if applicable, 250–500-character listing summary, canonical URL, actual demo, logo, current screenshots, accurate pricing/license/platforms, source/release/endpoint where relevant, company owner contact, and genuine category/competitor mapping.
